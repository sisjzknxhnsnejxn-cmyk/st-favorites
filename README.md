# SillyTavern 全局消息收藏夹扩展

一个纯前端的 SillyTavern 扩展，支持跨聊天收藏消息、标签管理、全文搜索和批量导出。

## ✨ 核心特性

### 📌 智能收藏
- **一键收藏**：每条消息旁显示星标按钮，支持单人聊天和群聊
- **防重复收藏**：已收藏消息自动高亮星标，避免重复添加
- **原文保留**：支持保存原始文本或渲染后的 HTML 快照

### 🏷️ 标签与备注
- **自定义标签**：每条收藏可添加多个标签，支持批量编辑
- **备注功能**：为重要收藏添加个人备注
- **标签管理**：统一重命名或删除标签，自动同步到所有收藏

### 🔍 高效检索
- **全文搜索**：实时搜索消息正文、备注、标签和角色名
- **智能筛选**：按标签、角色、聊天记录快速筛选
- **二级分类**：自动按"角色 → 聊天记录"或"群聊 → 聊天记录"分类

### 📦 批量管理
- **多选模式**：支持批量删除、批量编辑标签
- **Markdown 导出**：导出选中收藏为格式化的 `.md` 文件
- **TXT 导出**：导出纯文本版本，自动清洗 HTML 和思维链标签 ✨
- **JSON 备份**：一键导入/导出所有收藏数据

### ☁️ 云端同步
- **三端互通**：数据保存在酒馆的 `settings.json` 中，云酒馆手机/平板/电脑自动同步
- **体积监控**：实时显示收藏数据占用空间
- **快照瘦身**：一键清理 HTML 快照，节省 70% 存储空间 ✨

### 🎨 多端适配
- **移动端优化**：支持触摸拖拽、安全区适配、防滚动穿透
- **懒加载**：大量收藏自动分页加载，避免卡顿
- **卡片折叠**：默认显示摘要，点击展开全文

### 🚀 多种入口
- **悬浮球**：可拖拽、自动贴边的快捷图标
- **扩展菜单**：顶部导航栏入口
- **魔法棒菜单**：输入框旁的快捷按钮
- **斜杠命令**：`/fav` 命令快速打开（可绑定 Quick Reply）

## 📥 安装方法

### 通过 SillyTavern 扩展管理器安装（推荐）

1. 打开 SillyTavern
2. 点击顶部菜单栏的 **扩展** 图标
3. 点击 **从 URL 安装扩展**
4. 粘贴以下链接：
   ```
   https://github.com/sisjzknxhnsnejxn-cmyk/st-favorites
   ```
5. 点击 **安装**
6. 刷新页面后即可使用

### 手动安装

1. 下载本仓库的所有文件
2. 将文件夹重命名为 `st-favorites`
3. 移动到 SillyTavern 的 `public/scripts/extensions/third-party/` 目录
4. 重启 SillyTavern

## 🎯 使用指南

### 收藏消息
1. 在聊天界面中，每条消息展开后会显示星标按钮（⭐）
2. 点击星标收藏当前消息
3. 已收藏的消息星标会保持高亮

### 查看收藏
- **方式 1**：点击悬浮球（可在设置中开启）
- **方式 2**：顶部菜单 → 扩展 → 消息收藏夹
- **方式 3**：输入框旁的魔法棒菜单 → 消息收藏夹
- **方式 4**：输入 `/fav` 命令

### 管理标签
1. 在收藏面板中点击 **标签管理**
2. 可以重命名或删除标签
3. 修改会自动应用到所有相关收藏

### 批量操作
1. 点击 **批量管理** 进入多选模式
2. 勾选需要操作的收藏
3. 可以批量删除、批量编辑标签、导出为 Markdown 或 TXT

### 导入/导出
- **导出 Markdown**：批量操作 → 选择收藏 → 导出为 Markdown
- **导出 TXT**：批量操作 → 选择收藏 → 导出为 TXT（自动清洗 HTML）
- **导出 JSON**：设置面板 → 导出为 JSON（备份所有数据）
- **导入 JSON**：设置面板 → 从 JSON 导入（恢复备份）

### 快照瘦身
如果收藏数据占用空间过大：
1. 打开设置面板
2. 点击 **清理 HTML 快照**
3. 确认后自动清理所有快照，可节省约 70% 空间

## ⚙️ 配置选项

在扩展设置面板中可以自定义：

- **全局入口**：开启/关闭悬浮球、菜单入口、斜杠命令
- **显示模式**：纯文本模式或保留美化渲染
- **存储策略**：定格快照模式（占用较大）或实时渲染模式（节省空间）
- **UI 主题**：跟随 ST 原生主题
- **思维链标签**：收藏时是否包含 AI 思维链内容

## 🛠️ 技术架构

- **纯前端实现**：无需后端插件或服务器
- **模块化设计**：ES Modules 拆分职责，11 个 UI 组件
- **数据持久化**：使用 SillyTavern 的 `extensionSettings` API
- **版本管理**：内置 `schemaVersion` 支持平滑升级
- **测试覆盖**：核心存储和清洗逻辑包含 17 个单元测试，100% 通过
